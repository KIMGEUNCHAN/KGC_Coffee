적용방법.txt
WISVision IM — Void Good/NG 를 AlignData.csv 에 남길 때
작성: 2026-09-08

자세한 리스크는 같은 폴더
  AlignData_Void_리스크.txt


============================================================
1. 결론
============================================================

AlignData.csv 에 Void 판정을 넣어도 되는 경우는 하나다.
기존 정렬 행을 유지하고 맨 끝 열 VoidResult 만 GOOD/NG 로 갱신.

새 행 Append, 파일 Create, Offset/Result 칸 덮기는 문제 된다.


============================================================
2. 가져갈 파일
============================================================

  현장적용\AlignData_Void_리스크.txt
  IM\Logging\AlignDataVoidLogger.cs


============================================================
3. 호출
============================================================

Align 이 AlignData.csv 를 만든 뒤, Void 판정 직후

  AlignDataVoidLogger.WriteDieResult(strAlignCsv, strDieNo, "NG");
  AlignDataVoidLogger.WriteDieResult(strAlignCsv, strDieNo, "GOOD");

웨이퍼 종합이면 행을 추가하지 말고

  AlignDataVoidLogger.WriteWaferResult(strAlignCsv, "GOOD");

또는 더 안전하게

  clsLog.WriteLog("Void", "Die=" + strDieNo + " GOOD");


============================================================
4. VS 에서 확인할 것
============================================================

AlignData 검색 → Write 하는 곳의 FileMode
  Create 이면 Void 쪽에서 다시 Create 하지 말 것.

AlignData 를 Read / Parse 하는 곳
  열 개수 고정인지, 숫자 Parse 인지.

Void NG 후 Unload 전에 csv Flush 되는지.
끝.
