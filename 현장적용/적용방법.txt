WISVision IM — Void Good/NG 를 AlignData.csv 에 남길 때
작성: 2026-09-08

모순
  Good 이 아니면 AlignData.csv 를 저장하지 않는다.
  확인하고 싶은 것은 NG 와 Good 인데, 파일에는 Good 만 남는다.


============================================================
1. 현장 수정 (이 한 곳이 본체)
============================================================

VS 에서 SaveAlignData / AlignData.csv / FileMode 를 검색한다.
아래처럼 Good 가드 안에 저장이 있으면 밖으로 뺀다.

  // 현재 (모순)
  if (bVoidGood)
  {
      SaveAlignData();
  }
  else
  {
      ShowNgPopup();   // 파일 없음
  }

  // 수정: 저장을 팝업보다 먼저, 판정과 무관하게
  SaveAlignData();
  AlignDataVoidLogger.SaveAfterVoidInspect(
      strAlignCsv, strDieNo, bVoidGood ? "GOOD" : "NG");
  if (!bVoidGood)
  {
      ShowNgPopup();   // Unload / Manual Remove / Retry
  }

SaveAlignData() 가 메모리의 오프셋을 쓰는 함수면
NG 일 때도 그대로 호출해야 오프셋이 안 사라진다.
그 다음 VoidResult 칸만 GOOD/NG 로 찍는다.


============================================================
2. 가져갈 파일
============================================================

  현장적용\AlignData_Void_리스크.txt
  IM\Logging\AlignDataVoidLogger.cs


============================================================
3. 확인
============================================================

Void Good 1장 → AlignData.csv 에 VoidResult=GOOD
Void NG 1장  → AlignData.csv 가 있고 VoidResult=NG
Unload 해도 파일이 남아 있어야 한다.

csv 에 Good 만 있으면 아직 if (bGood) 가드가 남은 것이다.
끝.
