# 한달

한 달에 한 번, 자산과 책과 몸과 사람을 적는 점검 페이지입니다.

매일, 매주는 비워 두었습니다. 숫자를 채우는 일이 아니라, 달을 넘길 때 한 번 앉아 적는 쪽에 맞춰져 있습니다.

## 적는 것

- **자산.** 퇴직연금(지수투자, 반도체), 토스증권(배당주, 개별주, 지수투자, 이번 달 배당금), ISA(지수투자, 반도체). 평가액은 만원, 배당금은 원입니다. 배당금은 합계에 넣지 않습니다.
- **독서.** 매년 12권. 다 읽은 책만 목표에 들어갑니다.
- **체중.** 그달의 아침 몸무게 하나.
- **사람.** 고마웠던 사람, 오래 못 본 사람, 다음 달에 먼저 연락할 사람.
- **한 문장과 다음 달의 하나.** 이번 달을 한 줄로 남기고, 다음 달에 지키면 되는 것 하나만 적습니다. 다음 달 첫 화면에 다시 보입니다.

수면, 운동, 기분처럼 일주일 안에도 바뀌는 것은 일부러 넣지 않았습니다.

## 기록은 어디에

이 브라우저의 `localStorage`에만 있습니다. 오른쪽 아래의 내보내기로 JSON 파일을 받아 두고, 다른 기기에서는 가져오기로 이어 갑니다.

## 실행

```bash
npm install
npm run dev
```

`npm test`로 금액 합계와 저장 형식을 확인하고, `npm run build`로 정적 파일을 만듭니다.
